# Security policy

## Reporting a problem

If you find a security or privacy problem in Burg Archive, please report it privately:

- email **support@burgmedia.eu**, or
- use **Report a vulnerability** on the Security tab of this repository.

Please do not open a public issue for security problems. Include the version (see `manifest.json`), your browser and version, and the steps to reproduce. We will confirm that we received your report and keep you informed while we work on a fix.

## Supported versions

Only the latest release, as published in this repository and in the Chrome Web Store, receives fixes.

## Scope

In scope: the code in this repository. Out of scope: the burgmedia.eu website (report website problems to the same address, but they are handled separately) and problems in Chrome itself.
